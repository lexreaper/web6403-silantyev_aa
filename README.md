# Лабораторная работа №2

**Тема:** Разработка многостраничного веб-сайта с использованием HTML и CSS.

**Цель:** Изучение основ HTML и CSS.

### Описание проекта

**Game Zone** — многостраничный информационный сайт, посвящённый компьютерным играм.

Сайт состоит из трёх страниц:

- **Главная (`index.html`)** — приветственный экран и подборка популярных игр.
- **Игры (`games.html`)** — каталог из пяти игр с изображениями, описаниями и сравнительной таблицей.
- **О сайте (`about.html`)** — информация о проекте и использованных технологиях.

### Использованные технологии

- **HTML5** — структура и содержимое страниц.
- **CSS3** — оформление, сетки, цвета и эффекты наведения.

JavaScript, Bootstrap и сторонние библиотеки не используются.

### Структура проекта

```text
lab2/
├── index.html
├── games.html
├── about.html
└── style.css
```

### Реализованные возможности

- Навигация между страницами.
- Отображение изображений и описаний игр.
- Таблица с выравниванием текста по левому краю, центру и правому краю.
- Оформление страниц с использованием внешнего CSS-файла.
- Эффекты наведения на элементы интерфейса.
- Ссылки на внешние ресурсы.

### Запуск

Открыть файл `lab2/index.html` в браузере.

# Лабораторная работа №3

**Тема:** Основы JavaScript.

**Цель:** Изучение основ JavaScript.

### Описание работы

В папке `lab3` размещён каркас проекта, в котором реализованы 10 функций на JavaScript:

- `isInteger()` — проверка, является ли число целым.
- `even()` — получение чётных чисел от 2 до 20.
- `sumTo()` — сумма чисел от 1 до заданного числа с помощью цикла.
- `recSumTo()` — вычисление суммы с помощью рекурсии.
- `factorial()` — вычисление факториала.
- `isBinary()` — проверка, является ли число степенью двойки.
- `fibonacci()` — вычисление числа Фибоначчи.
- `getOperationFn()` — создание функции, выполняющей заданную операцию.
- `sequence()` — генератор арифметической последовательности.
- `deepEqual()` — сравнение значений, массивов и вложенных объектов.

### Использованные технологии

- **JavaScript** — реализация функций.
- **Node.js** — запуск проекта и проверок.

### Проверка работы

Для проверки правильности работы функций используются готовые тесты из файла `core.spec.js`.

В папке `lab3` выполнить:

```bash
npm install
npm test
```

О ПРОЕКТЕ

Game Zone

Учебный многостраничный сайт, обновлённый в рамках лабораторной работы №4 по дисциплине «Web-программирование».

01

HTML

На страницах используются заголовки, абзацы, ссылки, изображения, таблица, блочные и строчные элементы.

02

CSS

Оформление сайта вынесено в отдельный CSS-файл. Используются цвета, сетка, карточки, выравнивание и эффекты наведения.

03

Навигация

Сайт состоит из четырёх связанных страниц: главной страницы, каталога игр, страницы с информацией о проекте и страницы регистрации.

Полезный ресурс

Дополнительную информацию об HTML и CSS можно найти на MDN Web Docs .
